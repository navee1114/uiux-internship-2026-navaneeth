# WaterWise – Daily Water Intake Tracker

## Project Overview

WaterWise is a mobile application designed to help users maintain healthy hydration habits by making water intake tracking simple, quick, and engaging. The app allows users to set a daily hydration goal, log water consumption with a single tap, receive timely reminders, and monitor their daily progress through clear visual indicators.

## Problem Statement

Many people do not drink enough water because they forget to stay hydrated or find existing health-tracking apps too complicated. Dehydration can reduce concentration, energy levels, and overall well-being. WaterWise addresses this problem by providing a clean, intuitive, and user-friendly interface that encourages users to achieve their daily hydration goals.

## Features

* Set a personalized daily water intake goal.
* Track daily water consumption with quick-add buttons.
* Log custom water intake and select different drink types.
* Configure reminder notifications at preferred intervals.
* View daily hydration progress and streak statistics.
* Monitor water intake using visual charts and progress indicators.

## Design Decisions

The application follows a modern and minimalist design approach to provide a smooth user experience.

* **Color Palette:** Blue and white colors represent freshness, water, and wellness.
* **Typography:** Clean, readable fonts with a clear visual hierarchy.
* **Layout:** Simple navigation with rounded cards, large buttons, and generous spacing.
* **User Experience:** One-tap interactions reduce effort and encourage regular use.
* **Visual Elements:** Circular progress indicators, icons, and charts motivate users to stay hydrated.

## Screens Included

### 1. Welcome / Setup

Allows users to enter their daily water intake goal and start using the application.

### 2. Home / Water Tracker

Displays the daily hydration progress with a circular progress indicator, quick-add buttons, and today's water consumption.

### 3. Log Water Entry

Enables users to log custom water intake, choose a drink type, and record the current time.

### 4. Reminder Settings

Allows users to enable reminders, select reminder intervals, and configure active notification hours.

### 5. Daily Summary

Shows total water consumed, daily goal achievement, hourly intake chart, hydration streak, and motivational messages.
